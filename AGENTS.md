# AGENTS.md

## Sobre o projeto

Implementação do [TabNews](https://www.tabnews.com.br) para o [curso.dev](https://curso.dev), construída com a ajuda de agentes de IA.

## Comandos

- `npm install`: instala as dependências
- `npm run dev`: servidor de desenvolvimento (http://localhost:3000)
- `npm run build`: build de produção
- `npm start`: serve o build de produção

## Convenções

- Preferir a solução mais simples possível, com o mínimo de código.
- Seguir as convenções modernas do Next.js.
- Textos, mensagens de commit e documentação em português.
- Branch principal: `main`.
